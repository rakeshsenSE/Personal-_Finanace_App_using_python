# 📱 Expense Tracker App

Welcome! This is a simple, lightweight, and efficient **Expense Tracker CLI (Command Line Interface) Application** built using Python. This application helps you easily log, manage, and track your daily expenses right from your terminal.

---

## 🚀 Features

* Add Expense: Log your expenses quickly by entering the date, category (e.g., Dress, Book, Food), and the specific amount.
* View All Expenses: Display a well-formatted, chronological list of all your recorded expenses with individual item counts.
* View Total Amount: Calculate and display the cumulative sum of all your expenses instantly with a single command.
* User-Friendly Interface: A clean, infinite menu-driven loop designed for a smooth and intuitive user experience.

---

## 🛠️ Technologies Used

* Programming Language: Python 3.x
* Core Concepts:Loops (`while`), Conditional Control Flow (`if-elif-else`), Data Structures (Lists & Dictionaries), Dynamic String Formatting (f-strings).

---

## 💻 How to Run

Follow these simple steps to set up and run the project locally on your machine:

1. Make sure you have **Python** installed on your system.
2. Create a new python file named `app.py` and paste the source code into it.
3. Open your terminal or Command Prompt (CMD) in that specific folder and execute the following command:

```bash
python app.py
